This release of LoopTexturer, a VST® 3 insert plug-in for sound design, gives free running loops three times as much tape and fixes a rare crash.

## What's new

- **Longer free running loops:** the length now runs from 500 ms to 30 s, up from 10 s.

## What's fixed

- **A rare crash in the looper:** the plug-in could free a tape just as the audio thread started using it. In version 1.0.0, this could happen when tempo sync mode swapped in a larger tape.

## Upgrading

Projects saved with version 1.0.0 still open with their loop, length and pitch unchanged. A loop from an older project keeps its 10 s tape until you clear it, and the next recording then gets a 30 s tape. On that older tape, overdubs made with the length above 10 s are lower quality.

- **Length automation:** if a project has automation on the looper's length, it plays back at different lengths from before, because hosts store it as a position on the knob's range. Redraw any that you want to keep.
- **Going back:** version 1.0.0 can't read the plug-in's state from projects saved with this version.
- **Resources:** each instance uses 11.5 MB of memory at 48 kHz instead of 3.84 MB, and saving a free running loop adds that much to the project, whatever its length. Short loops also use more CPU, because the tape runs three times as fast.

## Installing

Download `LoopTexturer-1.1.0-Setup.exe` below and run it. It replaces any previous version and installs to `C:\Program Files\Common Files\VST3`, which is where DAWs look by default. You can remove it from Windows' Installed apps.

**Windows will probably warn you when you run it,** because the installer isn't code-signed. To continue, choose **More info**, then **Run anyway**.

## Requirements

- Windows 10 or later, 64-bit
- A VST 3 host. LoopTexturer is developed and used in Cubase, and other hosts haven't been tried. Dragging to the timeline depends on the host accepting file drops from a plug-in window.
