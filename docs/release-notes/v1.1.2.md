This release of LoopTexturer, a VST® 3 insert plug-in for sound design, fixes the output breaking for good after a single bad audio sample.

## What's fixed

- **Broken input samples:** a NaN or infinite sample arriving at the input stayed in the filter, so that the output didn't recover by itself, and it could be recorded into the loop. These samples now become silence before anything else in the chain.

## Upgrading

Projects saved with earlier versions open and sound as they did, and the saved format hasn't changed since version 1.1.0, so that version can still open projects saved with this one. Before this release, its audio, saved state and parameter text were compared with version 1.1.0's, and the only difference is in how it handles broken samples.

## Installing

Download `LoopTexturer-1.1.2-Setup.exe` below and run it. It replaces any previous version and installs to `C:\Program Files\Common Files\VST3`, which is where DAWs look by default. You can remove it from Windows' Installed apps.

**Windows will probably warn you when you run it,** because the installer isn't code-signed. To continue, choose **More info**, then **Run anyway**.

## Requirements

- Windows 10 or later, 64-bit
- A VST 3 host. LoopTexturer is developed and used in Cubase, and other hosts haven't been tried. Dragging to the timeline depends on the host accepting file drops from a plug-in window.
